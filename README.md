## 🚀 ICeCream 核心能力 | Core Capabilities

<table>
<tr>
<td width="50%" valign="top">

### 🧮 约束引擎
**硬约束 DSL + 软约束压力评分 + 冲突检测**

将学校排课中的真实业务规则（教师时间、教室容量、连堂课、跨年级限制等）编码为形式化约束，毫秒级冲突检测。

</td>
<td width="50%" valign="top">

### ⚡ 智能求解器
**难度排序 + 压力评分 + 递归换位 + Tabu 搜索**

多阶段启发式求解策略，自动识别高难度课节优先排布，结合禁忌搜索跳出局部最优。

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📐 GeoGebra Studio
**AI 命令规划 + 离线互动画布 + 课件导出**

集成 GeoGebra HTML5 离线运行时，通过 AI 自动生成动态几何命令，支持导出可嵌入 PPT 的互动课件包。

</td>
<td width="50%" valign="top">

### 🎬 Manim 动画
**意图识别 + 代码生成 + 渲染 + Studio 预览**

Python Manim 服务从自然语言生成数学动画，完整的 agent 流程覆盖意图分析到视频渲染。

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🔍 诊断系统
**未排归因 + 冲突定位 + 修复建议**

排课失败时自动分析原因链，精确定位冲突约束，生成可操作的修复建议。

</td>
<td width="50%" valign="top">

### 🖥️ 可视化工作台
**三栏响应式布局 + React-Konva 课表网格**

拖拽式课表编辑、实时冲突高亮、多维度视图切换，800+ 测试用例零失败。

</td>
</tr>
</table>
