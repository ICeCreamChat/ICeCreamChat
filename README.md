## 🎯 About Me

> 专注教育科技领域，正在构建新一代 **智能排课系统** —— 类 FET 严肃求解引擎 + 本土学校规则 + 现代交互体验。

- 🔭 当前项目：**ICeCream 智能排课 2.0** —— 从约束建模到求解优化，再到可视化工作台的全链路排课引擎
- 🌱 技术栈：Node.js ESM / Express / React 19 / Konva / Playwright
- 💡 兴趣方向：组合优化、启发式算法、约束满足问题 (CSP)、教育信息化
- 📫 欢迎交流排课算法、教育 SaaS 系统设计

## 🔥 Featured Project — ICeCream 智能排课

- 🧩 **约束引擎**：硬约束 DSL、软约束压力评分、冲突检测
- 🧠 **求解器**：难度排序(nIncompatible) + 压力评分 + 递归换位 + Tabu 搜索
- 📥 **多源导入**：支持水晶排课、Excel、yqd 等格式迁移
- 🔍 **诊断层**：未排归因、冲突定位、修复建议
- 🖥️ **可视化工作台**：三栏响应式布局 + React-Konva 课表网格
- 🧪 **验证门禁**：800+ 测试用例零失败，Playwright 端到端验证
