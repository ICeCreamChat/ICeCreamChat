## 🍦 关于 | About

> **ICeCream** 是一个面向学习和教学场景的本地 AI 工作台。
> 把 AI 对话、题目解析、数学动画、动态几何、智能排课、座位规划放在同一个浏览器入口里，
> 方便课堂工具和实验能力继续扩展。

```text
🏫 定位        面向课堂的本地 AI 教学工具箱
🧠 技术方向    LLM 应用 / 数学可视化 / 组合优化 / 教育 SaaS
🔧 技术栈      Node.js · React 19 · Python 3.12 · Java 21
🌐 开放交流    欢迎对教育科技、AI 教学工具感兴趣的朋友交流
```

## ✨ 核心能力 | Capabilities

<table>
<tr>
<td width="33%" valign="top">

### 💬 AI 对话 & 解题
统一接入大模型，支持普通对话、流式对话和多模态图片解题，OCR 文档解析链路完整。

</td>
<td width="33%" valign="top">

### 🎬 Manim 动画
从自然语言生成数学动画，完整 agent 流程覆盖意图分析、代码生成到视频渲染，内置 Studio 预览。

</td>
<td width="33%" valign="top">

### 📐 GeoGebra Studio
集成离线 GeoGebra HTML5 画布，AI 自动生成动态几何命令，支持导出可嵌入 PPT 的互动课件包。

</td>
</tr>
<tr>
<td width="33%" valign="top">

### 📅 智能排课
约束求解引擎 + Timefold Solver，从数据导入、自动排课到冲突诊断和可视化工作台的完整方案。

</td>
<td width="33%" valign="top">

### 💺 座位规划
名单解析、AI 辅助座位安排、布局预览、评分导出，支持自然语言和图片输入。

</td>
<td width="33%" valign="top">

### 🧩 可扩展架构
Gateway 统一入口 + 微服务拆分，新课堂工具和实验能力可以快速接入。

</td>
</tr>
</table>
