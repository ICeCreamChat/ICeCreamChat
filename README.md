## 项目 | Projects

### ICeCream 智能排课系统

全链路排课引擎，从约束建模到可视化工作台的完整方案。

- **约束引擎** — 硬约束 DSL + 软约束压力评分 + CHOOL冲突检测
- **求解器** — 难度排序(nIncompatible) + 压力评分 + 递归换位 + Tabu 搜索
- **数据导入** — 支持水晶排课、Excel、yqd 等多格式迁移
- **诊断系统** — 未排归因、冲突定位、修复建议
- **工作台** — 三栏响应式布局 + React-Konva 课表网格
- **质量门禁** — 800+ 用例零失败，Playwright 端到端验证
